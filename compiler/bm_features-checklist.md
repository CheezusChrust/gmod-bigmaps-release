# bm_features in-game checklist

Map generated by [make_feature_vmf.py](make_feature_vmf.py), compiled
with the patched vbsp++ + stock `vvis++ -fast` + stock `vrad++ -bounce 2 -noextra`; all
three must exit with no warnings. Room: X/Y −31744…31744, floor at Z 0, sky ceiling at Z 30720,
a well down to Z −30720.

Historical reference pass: build 25375506 with file-patched copies and the patched compiler,
2026-11-02, every item OK including item 10. This was not a two-client test of the current module.
(BSP SHA-256 `923A557A739D07285FF24978FD4F04381E37F974C8F8610F3C0E2D92249CC95A`).

## Setup

1. Install the [runtime module](../docs/INSTALL.md) on compatible stock files.
2. Copy `bm_features.bsp` to `GarrysMod\garrysmod\maps\`.
3. Use a supported Windows game architecture; single-player is fine for everything except item 10. Console:
   `map bm_features`, then `sv_cheats 1` (for setpos and buildcubemaps). Teleport with the
   setpos lines below; use noclip to get around.
